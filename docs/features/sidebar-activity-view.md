# 侧边栏活动视图

状态：当前合同
更新日期：2026-09-03

## 目标

侧边栏提供两种会话阅读方式：

- 项目视图按项目与会话层级组织内容，适合在单个项目内连续工作。
- 活动视图汇总全部项目的会话，按待处理状态和最近活动时间组织内容，适合在多个项目之间切换。

活动视图入口位于侧边栏顶部。视图选择保存在本机，应用重启后继续使用上次选择。

## 优先级

优先级是运行状态的派生分组，不是可手动设置的会话字段。

以下会话进入优先级分组：

1. 等待用户输入，包括权限确认和 Agent 提问。
2. 正在运行，包括普通会话和运行中的委派子任务。

分组内先显示等待用户输入的会话，再显示正在运行的会话；相同状态按更新时间倒序排列。

## 日期分组

未进入优先级的会话按更新时间进入日期分组：

- 今天
- 昨天
- 最近六天内的星期名称
- 当年的月日
- 跨年的年月日
- 无法解析时间时归入更早

日期分组和组内会话均按时间倒序排列。当前选中的会话只更新选中反馈，不改变所在分组和位置。

## 整理时机

进入活动视图时创建一次布局快照。活动视图保持打开期间遵循以下规则：

- 空闲会话开始运行或开始等待用户输入时，立即进入优先级。
- 优先级中的会话完成后保留当前位置，避免用户跟进时列表突然跳动。
- 新建并进入的会话首帧直接出现在优先级，不经过日期分组。
- 会话被删除后从当前快照移除。
- 搜索只过滤当前结果，不重建分组和顺序。

离开活动视图后，当前快照结束。再次进入时根据最新状态和更新时间重新生成布局。界面不提供手动整理按钮。

## 交互反馈

- 点击会话后立即更新选中态，会话内容切换作为非紧急渲染继续执行。
- 折叠或展开侧边栏时，主内容区只进行一次布局切换；视觉过渡使用位移和裁剪动画，时长为 200ms。
- 动画期间侧边栏边界与主内容区保持贴合，侧边栏文字不参与逐帧宽度重排。
- 系统启用减少动态效果时停用过渡动画。
