# 长会话轮次导航

状态：已完成

更新日期：2026-09-03

## 目标

单个会话包含较多交互轮次时，用户可以快速预览历史问题，并定位到对应的用户消息。

## 产品合同

- 会话包含至少 5 个已发送用户轮次时，在消息区域左侧显示轮次导航。
- 用户轮次只包含已发送的用户消息，不包含助手消息和仍在排队的消息。
- 静止状态下所有轮次标记长度一致，当前阅读轮次使用深色标识。
- 鼠标进入导航区域后，目标轮次形成最长标记，相邻轮次按照距离逐级缩短。
- 悬停或键盘聚焦轮次时，显示轮次序号、发送时间和用户消息摘要。
- 点击轮次后滚动到对应用户消息，并短暂高亮消息区域。
- 用户正常滚动时，当前轮次根据阅读位置更新；位于会话底部时选择最后一个用户轮次。
- 轮次数量超过可视高度时，标记列表可以独立滚动，并保持当前轮次可见。
- 系统开启减少动态效果时，定位使用即时滚动，轮次选择和目标反馈仍保持可识别。

## 验证

- L1 覆盖轮次过滤、消息摘要、当前轮次计算和波形比例。
- Local Product E2E 覆盖静止状态、悬停预览、波峰变化、点击定位、目标高亮和当前轮次更新。
