# Zora v0.1.18

发布日期：2026-09-13

## 数据迁移

- 新增迁出与迁入指南，展示本机实际数据目录，并提供可直接复制给 Zora 的任务提示词。
- 迁出按原样打包完整数据目录，保留隐藏文件、目录层级和符号链接。迁入时检查数据与覆盖范围，并按新设备实际情况关联项目目录。
- 支持添加 ZIP 等普通文件附件；较大的本地文件通过路径引用交给 Agent，避免重复复制。
- 托管目录和项目内目录使用相对引用，整体移动数据或重新关联项目后，原有会话继续定位对应文件。

## 项目管理

- 编辑项目时可同时修改名称和本地文件夹，新增打开本地文件夹入口，删除操作改为“移除项目”。
- 项目目录不可用时，仍可查看历史、继续旧会话并使用可访问的附件；重新关联后可继续访问项目文件。
- 单个技能目录或符号链接不可读取时跳过该项，避免启动被中断。

## 界面修复

- 迁出和迁入使用一致的目录栏，打开操作统一放在右侧，采用文字与外跳图标。
- 提示词默认展开在独立卡片内，右上角提供复制按钮与成功反馈。
- 修复编辑项目时路径输入区域的垂直对齐；长路径保持单行，悬停可查看完整路径。

## 升级说明

- 启动时自动将历史目录记录升级为可迁移的路径格式，并将配置与应用记录整理到 `config/`、`state/`；转换前内容保存在 `backups/`。
- 外部项目路径保留原绑定，换机后可通过“编辑项目”选择本机文件夹。
- 原样打包的符号链接不包含其指向的外部文件内容。恢复时先准备数据和备份，在目标应用退出后放入数据并重新启动。
