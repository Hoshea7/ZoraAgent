# Zora v0.1.16

发布日期：2026-08-30

## 对话体验

- 新增回复批注。可以为回答内容添加批注，并在流式输出和滚动过程中保持批注位置稳定。
- 新增用户消息操作，便于对已发送内容继续处理。
- 修复运行中会话在页面重载后恢复时，助手回复可能重复显示的问题。
- 修复 Markdown 中单个波浪线范围的解析，避免内容被错误格式化。

## 模型与 Provider

- 支持多模型目录，可在同一 Provider 中管理和选择多个模型。
- 调整 Provider 和模型配置界面，完善新增、编辑、删除及删除确认流程。
- 连接测试和模型探测统一通过 Pi Runtime 执行，使测试路径与实际对话保持一致。
- 恢复旧版 Provider 配置的 v1 迁移，并移除过时的模型配置回退路径。

## 运行稳定性

- 提高输出预算，并将上下文压缩与输出预算解耦，减少长回复受上下文处理影响的情况。
- 调整附件存储和视觉内容转发路径，保证附件与视觉输入在运行时按同一规则处理。
- 升级 Pi 运行时依赖。

## 测试与发布

- 测试体系按单元、集成和端到端三个层级整理，并为端到端用例增加产品与 Agent 覆盖标记。
- 发布工作流使用本说明作为 Release 内容，同时保留 GitHub 自动生成的提交列表。

## 升级说明

- 现有 Provider 配置会在读取时完成 v1 格式迁移，无需手动修改配置文件。
