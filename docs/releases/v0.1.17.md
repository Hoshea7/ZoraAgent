# Zora v0.1.17

发布日期：2026-09-03

## 会话管理

- 新增侧边栏活动视图，汇总所有项目中的会话，并按优先级与最近活动日期排列。
- 优先级根据等待用户输入和运行中状态自动生成。任务完成后在当前访问中保持原位，重新进入活动视图时再归入对应日期。
- 点击会话只更新选中反馈，不会立即改变列表顺序。新建会话首帧直接进入优先级，减少位置跳动。
- 支持使用 `⌥⌘U` 切换活动视图；Windows 使用 `Alt+Ctrl+U`。视图选择会在应用重启后恢复。
- 活动视图沿用现有搜索能力，可同时匹配项目与会话。

## 长会话导航

- 会话包含至少 5 个用户轮次时，在消息区域左侧显示轮次导航。
- 悬停或键盘聚焦轮次标记时，可以预览轮次序号、发送时间和用户消息摘要。
- 点击轮次标记可定位到对应用户消息，并提供短暂高亮反馈。
- 用户滚动会话时，导航会同步当前阅读轮次；轮次较多时，导航区域可以独立滚动。
- 系统开启减少动态效果时，轮次定位使用即时滚动。

## 交互与性能

- 会话切换时立即更新侧边栏选中态，正文加载在后续渲染中继续执行。
- 调整侧边栏折叠和展开方式，主内容区只发生一次布局切换，避免长会话正文逐帧重排。
- 侧边栏内容使用固定宽度裁剪，减少展开过程中标题和副标题被挤压的情况。
- 补充真实 Electron 性能用例，验证长会话折叠期间的布局次数和边界连续性。

## 测试与发布

- 增加活动分组、快照更新、日期格式和视图持久化的单元测试。
- 增加活动视图、侧边栏折叠性能和长会话轮次导航的本地产品端到端测试。
- 修复发布任务读取版本说明的检出流程，确保 tag 构建可以使用对应版本文档生成 GitHub Release。

## 升级说明

- 本版本不需要迁移工作区或 Provider 配置。
- 原项目视图、项目层级、会话置顶和拖动操作保持原有用法。
