# L3-TASK-001 任务面板手动任务闭环

## 目标

验证用户能在当前工作区完成“进入任务面板 → 新建 → 查看 → 重启后仍存在 → 删除”的完整可见流程，并确认其他主入口未被破坏。

## 前置条件

- 使用隔离 HOME 启动 Zora，已完成初始化并进入主界面。
- 至少有一个可用工作区。

## 操作与预期

1. 观察展开态侧边栏底部：能看到“任务”入口，且与“定时”“设置”并列。
2. 点击“任务”：主区显示任务面板、空列表提示和“+ 新建任务”按钮。
3. 点击“+ 新建任务”，填写标题“验证任务持久化”、描述“重启后仍能看到”，点击“创建任务”。
4. 列表立即出现该任务及 `todo` 标签；右侧详情显示同样的标题、描述、负责人 `zora` 和触发方式 `manual`。
5. 完全退出 Zora 后，用同一隔离 HOME 再次启动，进入同一工作区和任务面板：该任务仍存在。
6. 点击详情中的“删除”：任务从列表消失，面板恢复空状态。
7. 分别点击“定时”“设置”，再回到对话主区：各入口都能正常切换。
8. 折叠侧边栏：能看到任务图标，点击后仍能进入任务面板。

## 通过标准

以上 8 步全部符合预期；任何一步无法被直接看到、点击或验证，都视为未通过。
